# ⚔️🐉 苍岚战纪

手机网页上玩的单机 RPG：**三职业 · 打怪爆装备 · 强化 · 红名恶徒 · BOSS · 挂机**。
在《晨曦村物语》的引擎上改的：登录、云存档、地图、任务、家园、杂货铺都沿用，战斗和装备换成了老式打怪爆装的玩法。
名字、职业、技能、装备、地图、怪物全部是原创的，没有用任何别的游戏的素材。

用邮箱注册后才能玩，进度**实时保存到云端**（Cloudflare D1），换手机登录也能接着玩。

## 玩法

结构上尽量贴近老式打怪爆装的网游：人物小、视野大、地图大、洞穴分层、技能要买书学还要练级、每 5 级换一把武器。
名字、怪物、地图、数值都是自己重新做的，没有照搬任何一款游戏。

| 系统 | 说明 |

## 目录结构

```
public/                 ← 网页（静态文件）
  index.html
  style.css
  game.js               ← 全部游戏逻辑
  manifest.webmanifest  ← 可“添加到主屏幕”
  icon.svg
functions/api/[[route]].js  ← 后端：注册、登录、云存档（和晨曦村物语完全一样）
schema.sql              ← 数据表（可选，后端会自动建表）
```

## 部署到 Cloudflare Pages

和晨曦村物语的步骤一样，**但要新建仓库、新建 D1 数据库**，不要和旧游戏共用，否则两边存档会互相覆盖。

1. **上传到 GitHub**：新建仓库（例如 `canglan`），把本目录所有文件上传，`functions` 文件夹必须在仓库根目录。
2. **创建 D1 数据库**：Cloudflare 控制台 → 存储和数据库 → D1 → 创建，例如 `canglan-db`。
3. **创建 Pages 项目**：Workers 和 Pages → 创建 → Pages → 连接到 Git → 选这个仓库。框架预设：无；构建命令：留空；构建输出目录：`public`。
4. **绑定数据库**：Pages 项目 → 设置 → 绑定 → 添加 → D1 数据库，变量名称 **`DB`**（大写），选第 2 步建的库。
5. **重新部署一次**（绑定要重新部署才生效）。
6. 打开 `xxx.pages.dev`，注册邮箱，选职业开玩。

本地运行（可选）：

```bash
npx wrangler pages dev public --d1 DB=local-db
```

## 改数值

都在 `public/game.js` 里：

- `CLASSES`：三个职业的血、防、攻、蓝倍率，攻击距离和间隔。
- `SKILLS`：技能的学习等级、冷却、耗蓝、说明；效果在 `castSkill` 和 `playerAttack` 里。`SK_PTS` 是升到 1/2/3 级要的熟练度，`SK_LVADD` 是要求的人物等级，`bookPrice` 是书价。
- `CURVE`：怪物属性按等级查的表（血、攻、防、经验、金币）。`MONS` 里每只怪写的是等级和倍率，`mon(名字, 图标, 等级, 掉落, {hp, atk, size, spd})`。
- `ZONES`：地图。`BIG` / `DUN` 是野外和洞穴的边长，`max` 怪物数，`prev` / `next` 把洞穴的几层连起来。
- `WPN_NAMES` / `ARM_NAMES` / `GEAR_TIERS`：装备名字。`TIER_LV`：穿戴等级。`gearStats`：各部位基础属性。
- `QUALITY` / `rollQuality`：品质倍率和出货概率。`killEnemy` 里「装备掉落」那段是掉率。
- `ENH_RATE` / `enhanceCost`：强化成功率和花费。`spawnRogue`：红名恶徒强度。
- `resize` 里的 `G.scale`：镜头远近（数字越小人物越小、看得越远）。
- `ITEMS / HOUSE / SHOP_LEVELS`：物品、家园、杂货铺，和晨曦村物语一样的改法。

**每次更新**：把 `game.js` 顶部的 `VERSION` 和 `index.html` 里的 `?v=` 改成新号码，手机就会自动加载新版。

## 说明

- 这是单机游戏：红名恶徒是 AI，没有真人对战、行会、攻城。要做多人同屏得加实时服务器（Cloudflare Durable Objects），是另一个量级的工作。
- 存档和晨曦村物语不通用（装备系统不同），本机缓存的键名也换成了 `cl_` 开头。
- 密码使用 PBKDF2-SHA256（10 万次迭代）加盐保存，登录令牌 30 天有效，只存哈希。注册不发验证邮件，也没有“忘记密码”。
